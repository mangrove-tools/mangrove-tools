Small tools. Clear jobs. Naples roots.

Mangrove Tools is a curated library of free, in-browser calculators — and a public home for the Lead-Dev system that ships them.

What we make

Each tool does one job well: estimate newsletter revenue (LetterROI), build a sponsorship rate card (SponsorQuote), work backward from a paid subscriber goal (SubTarget), and more as the library grows. Calculations run in your browser. No accounts. No hard paywall on results.

How we grow

Free tools earn trust and can include relevant affiliate links after they’ve been useful. Separately, the Lead-Dev offers (template kit, cohort, and done-with-you setup) teach the agent operating system used to build this site.

Where we’re from

Mangrove Tools is built in Naples, Florida — Gulf Coast calm over generic “AI startup” noise.
