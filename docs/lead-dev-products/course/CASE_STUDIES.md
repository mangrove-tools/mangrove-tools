# Cohort Case Studies (Teaching Notes)

## Case A — Needle (iOS SwiftUI utility)

**Model:** Free allowance → subscription  
**Lesson:** Locked journey + non-goals beat “AI search app” ambition.  
**Phases mapped:**
1. Optimize monetization/query edge cases and tests  
2. Onboarding/results clarity, a11y  
3. App Store metadata/screenshots/privacy URLs  
4. Expand only with journey-fitting features (e.g. preview), not history/AI pivots  

**Review question for students:** Which non-goal protected Needle from becoming unshippable?

## Case B — Mangrove Tools (static niche tools)

**Model:** Niche affiliate + free calculators  
**Lesson:** Optimize/SEO the existing tool before inventing ten thin tools.  
**Phases mapped:**
1. LetterROI correctness + site hygiene  
2. Professional Gulf Coast brand UX  
3. Intent SEO for calculator queries  
4. Lead picks next niche tool with keyword + CTA rationale  

**Review question:** Why is “start a blog network” a Phase-4 failure mode here?
