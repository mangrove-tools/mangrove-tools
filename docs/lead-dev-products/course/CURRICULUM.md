# Ship With a Lead-Dev Agent — Cohort Curriculum

**Format:** 4-week cohort (or self-paced with weekly live reviews)  
**Outcome:** Participant leaves with `AGENTS.md`, a lead-dev session prompt, Phases 1–3 executed on their repo, and one approved Phase 4 expansion plan.  
**Class size:** 8–20 (small enough for real reviews)

---

## Promise

You will stop vibe-prompting. You will install an Agent OS on a real product repo and use AI as a sequenced lead developer.

---

## Week 0 — Onboarding (before Day 1)

**Deliverables from student**
- Repo access (or zip)  
- One-sentence product  
- Current monetization (none / ads / affiliate / sub / other)  
- Biggest pain: bugs, SEO, UX, or scope chaos  

**Staff prep**
- Confirm stack bucket (iOS / static site / Next / API / other)  
- Assign buddy or review pod  

**Homework**
- Read methodology article  
- Write a draft Product Contract (template in `assignments/01-product-contract.md`)

---

## Week 1 — Product Contract & Constitution

### Live session (90 min)
1. Why agents fail without corridors  
2. Case study A: Needle (journey + non-goals + monetization)  
3. Case study B: Mangrove (niche affiliate tools + phase order)  
4. Workshop: lock contracts in breakout pods  

### Examples reviewed in class
- Good contract vs vague “AI startup” brief  
- Over-scoped non-goals that still leave a shippable core  

### Assignment
- Finalize Product Contract  
- Draft `AGENTS.md` v0.1 for their repo (use closest stack template)

### Review rubric (staff)
| Criterion | Pass bar |
| --- | --- |
| Primary journey | ≤7 steps, testable |
| Non-goals | ≥5 explicit bans |
| Monetization | Named model + constraint |
| Stack lock | Named; “no second framework” |
| DoD | Build/validation commands present |

---

## Week 2 — Phases 1–2 (Optimize + Professional UX)

### Live session
1. Phase 1 audit checklist walkthrough  
2. Live demo on Mangrove or a volunteer repo  
3. UX professionalism: hierarchy, empty states, trust  

### Examples
- Before/after LetterROI clarity  
- “AI purple template” anti-patterns gallery  

### Assignment
- Run Phase 1 agent session; merge/fix real issues  
- Run Phase 2 polish pass (even if partial)  
- Submit before/after screenshots + changelog  

### Review rubric
| Criterion | Pass bar |
| --- | --- |
| Phase order honored | No new features before fixes |
| Defects closed | ≥3 concrete fixes shipped |
| UX | Primary journey clearer to a stranger |
| Scope control | No unauthorized stack rewrite |

---

## Week 3 — Phase 3 Discovery / SEO + Agent Discipline

### Live session
1. Top-tier SEO for tools/apps (intent, titles, canonicals, IA)  
2. App Store / store listing parallel for mobile students  
3. How to reject bad agent output fast  

### Examples
- Thin SEO page vs intent-matched tool page  
- Keyword stuffing rejection samples  

### Assignment
- SEO/discovery pass on existing surfaces only  
- Update sitemap/llms or store metadata checklist  
- Write “Agent rejection log” (3 bad ideas you refused)

### Review rubric
| Criterion | Pass bar |
| --- | --- |
| Metadata | Title/H1/description intent-matched |
| Technical | Canonical/OG or store equivalent present |
| Integrity | No fake reviews / doorway pages |
| Judgment | Rejection log shows taste |

---

## Week 4 — Phase 4 Expansion + Demo Day

### Live session
1. How a lead picks niche expansions  
2. Decision-note format (keyword, uniqueness, CTA, out-of-scope)  
3. Demo Day: 5-minute student showcases  

### Assignment
- Propose 3 expansion ideas; pick 1  
- Optional: implement thin vertical slice OR full tool if Phases 1–3 are green  
- Publish retrospective (what the constitution prevented)

### Review rubric
| Criterion | Pass bar |
| --- | --- |
| Niche rationale | Search intent + uniqueness clear |
| Monetization path | Honest (even if “none yet”) |
| Sequencing | Expansion didn’t reopen Phase 1 fires |
| Retro | Names ≥1 agent failure mode avoided |

---

## Office hours & reviews

- **Async reviews:** 48h turnaround on rubric forms  
- **Office hours:** 2× weekly, 60 min  
- **Pod reviews:** peers score with the same rubric (calibrates taste)

## Facilitator notes

- Never let a student “skip to Phase 4” without a written waiver.  
- Prefer smaller shipped fixes over theatrical rewrites.  
- Spotlight failures: best teaching moments are rejected agent ideas.
