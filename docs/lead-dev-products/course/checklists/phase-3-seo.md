# Phase 3 — SEO / Discovery Checklist

## Web / tools

- [ ] Meta description ~140–160 chars, human
- [ ] Single H1 aligned to intent
- [ ] Canonical absolute URL
- [ ] OG/Twitter tags + image
- [ ] Internal links home ↔ tools
- [ ] sitemap.xml + llms.txt updated
- [ ] JSON-LD only if honest
