# Lead-Dev Template Pack

Filled constitutions + session prompts for common stacks.

| Stack | Folder | Best for |
| --- | --- | --- |
| Static Netlify micro-tools | `static-netlify/` | Niche affiliate tool sites (Mangrove-style) |
| iOS SwiftUI utility | `ios-swiftui/` | Focused App Store utilities (Needle-style) |
| Next.js App Router | `nextjs-app-router/` | Marketing site + small app routes |
| Python FastAPI service | `python-fastapi/` | Small APIs / internal tools |

## How to use
1. Copy the folder’s `AGENTS.md` to your repo root (adapt names).  
2. Copy `LEAD_DEV_BUILD_PROMPT.md` into `docs/`.  
3. Fill bracketed `[[LIKE_THIS]]` bits.  
4. Paste the lead prompt into a fresh agent session.
