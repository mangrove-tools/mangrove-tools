# Design direction — Mangrove × Httpster craft

**Inspiration:** [httpster.net](https://httpster.net/) — curated, high-craft site indexes: strong brand presence, numbered work lists, calm type, confident negative space, intentional motion.

**Not a rebrand:** Keep Mangrove Gulf Coast tokens (paper / pine / terracotta, Fraunces + Outfit). Borrow *craft*, not palette clones from featured gallery sites.

## Principles

1. Brand is a hero-level signal on the first viewport.
2. Tools read like a curated index, not a dashboard of cards.
3. One job per section; hairline rules over boxes/shadows.
4. Motion for presence (staggered entrance, hover underline) — respect `prefers-reduced-motion`.
5. Footer is structured, not a single run-on sentence.

## Autonomously continue

Lead designer may keep shipping shell polish, trust/content pages, and niche tools in small batches without waiting for permission on routine reversible work.
