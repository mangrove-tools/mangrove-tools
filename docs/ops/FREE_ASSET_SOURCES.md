# Free asset sources — Mangrove curated

**Upstream library:** [The People’s Design Library](https://docs.google.com/spreadsheets/d/13GStMRQfbn5glWVkUPqFtW1oovyKhMDdRKD3m5cstBg/edit?gid=0#gid=0) (~8k links)  
**Mirror site:** https://tnorverto.github.io/peoples-design-library/  
**Role:** Inspiration + licensed freebies for polish — **not** a license to ship pirate packs or unclear MediaFire dumps.

## Rules for this repo

1. Prefer **clear free/commercial-use** licenses (MIT, CC0, Google Fonts, author “free for commercial”).  
2. **Never** commit cracked, “🏴‍☠️”, Softarchive, or mystery `.rar` packs.  
3. Prefer **SVG / CSS** over heavy raster textures (performance + static hosting).  
4. Keep Mangrove identity: paper / pine / terracotta — do not import purple SaaS kits.  
5. Icons are optional; typography + rules already carry the brand. If used, keep sparse.

## How to use on Mangrove Tools

| Need | Do this |
| --- | --- |
| Atmosphere depth | Tune `site.css` `.atmosphere` before adding image textures |
| Product presence | Prefer live tool UI / result vignette over stock mockups |
| Icons in studio steps | Inline SVG from Iconoir/Akar, 1–2 max per view |
| Marketing OG art | Optional Unsplash/Pexels coastal still — optimize &lt;150KB |
| Full Figma UI kits | **Don’t** dump into static HTML; extract tokens/ideas only |

## Explicitly out of scope from PDL

Pirate streaming, cracked font managers, MediaFire texture dumps, Telegram “GB of PNGs”, Y2K sticker packs, dark-mode gallery clones, 3D illustration marketplaces that fight the Gulf Coast calm brand.
