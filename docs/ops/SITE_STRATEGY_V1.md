# MangroveTools.com — Version 1.0 Strategy

## Target visitor

1. **Primary:** Newsletter creators who need a free calculator (LetterROI / SponsorQuote).  
2. **Secondary:** Solo builders who want a lead-dev agent OS (kit / cohort / DWY).

## Product positioning

Free single-purpose tools from Naples, Florida — plus a clear path to run AI coding agents like a lead developer.

## Primary conversion paths

| Path | Action |
| --- | --- |
| Tools | Use calculator → soft beehiiv affiliate CTA |
| Lead-Dev ladder | Read `/method/` → buy kit → join cohort → book DWY intake |

## Main visitor journeys

1. Search/home → tool → answer → leave or affiliate.  
2. Home → Method → Lead-Dev → placeholder CTA (owner wires later).  
3. Home → About → Contact / Privacy (trust).

## Strengths

- Clear tool directory  
- Solid SEO head tags on existing pages  
- Honest client-side privacy model  
- Distinct Gulf Coast brand (not generic AI purple)

## Weaknesses

- Thin trust shell (no about/privacy/contact)  
- No public methodology or product offers  
- Minimal nav  
- No automated link checks

## V1.0 scope

| Keep / improve | Add |
| --- | --- |
| Home, LetterROI, SponsorQuote | `/method/`, `/lead-dev/` |
| Brand system | `/about/`, `/privacy/`, `/contact/` |
| Affiliate configs (unchanged IDs) | Shared nav/footer |
| sitemap / robots / llms | Ops backlog + revenue setup docs |

## V1.1 roadmap (not required for V1.0)

- Wire live checkout / booking / waitlist URLs  
- Additional niche calculators (lead-dev chosen)  
- Optional email capture vendor (approval-gated)  
- Deeper case-study pages once metrics are owner-approved

## Pages to remove or consolidate

None. Do not delete existing tools.

## SEO strategy

- Tool pages: high-intent calculator queries  
- Method: “lead-dev prompting” / agent OS methodology  
- Lead-Dev: product intent for kit/cohort/DWY  
- Trust pages: brand + privacy clarity (low competition, high trust)

## Trust & credibility

- About: Naples, free tools, dual model — no invented testimonials  
- Privacy: client-side calc, no input POSTs, affiliate disclosure  
- Proof on Lead-Dev: Needle + Mangrove method framing only

## Accessibility & privacy requirements

- Focus-visible, semantic nav, mobile layouts  
- Never POST calculator inputs; no analytics SDK without approval

## Release requirements

- Branch `mangrovetools-development`  
- Manual QA documented  
- Production deploy requires owner approval  
- No live payments activated in V1.0
