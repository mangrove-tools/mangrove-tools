Mangrove Tools & calculators

What is Mangrove Tools?

Mangrove Tools is a Naples, Florida library of free, in-browser calculators for creators — and a public home for the Lead-Dev agent operating system used to ship them. Each tool does one job well: estimate newsletter revenue, build a sponsorship rate card, work backward from a paid revenue goal, and more as the library grows.

Calculations run in your browser. No accounts. No hard paywall on results. Free tools earn trust and can include relevant affiliate links after they’ve been useful. Full story on About Mangrove Tools.

Are the calculators free?

Yes. Core tools are free to use in your browser. Results are not gated behind payment. Some pages may include optional affiliate links to relevant platforms after the calculator has been useful.

Do calculators send my data anywhere?

No. LetterROI, SponsorQuote, SubTarget, and other in-browser calculators do not POST your inputs to Mangrove Tools servers. Values you type are used locally to compute results on the page.

Like most websites, our host may process standard request logs (for example IP address, user agent, and requested URL) to serve pages. We also use Google Analytics for aggregate traffic measurement. Calculator inputs are still not POSTed for tool math — they stay in your browser. See the privacy page for details.

What is SubTarget?

SubTarget is the inverse of LetterROI’s paid stream: you set a monthly revenue goal, subscription price, and platform fee, then get paying subscribers needed — with a low/high planning band. Optional annual mix and churn fields help refine the estimate. Calculations stay in your browser.

What are Media Kit Composer and Inventory Planner?

Media Kit Composer builds a print-ready one-page media kit from audience stats and rates. Inventory Planner models sponsorship capacity over time (slots × cadence × fill × exclusivity). Both stay in your browser.

Lead-Dev offers

Lead-Dev Prompting is a system for shipping real products with coding agents: constitution files, phased execution, and niche expansion — without framework chaos. Read the free methodology article or try the interactive walkthrough, use the free studio tools, then compare paid offers on the Lead-Dev page (including Offer Fit).

What free Lead-Dev studio tools exist?
  • Constitution Builder — starter AGENTS.md
  • Phase Gate — Phases 1–3 readiness
  • Niche Gate — expansion idea filter
  • Method Walkthrough — case-path forks
  • Offer Fit — which paid offer matches
What is the Lead-Dev Kit?

The Lead-Dev Kit is a template pack: filled AGENTS.md files and session prompts for common stacks. Copy, adapt, and ship. Stacks included in the pack:

  • Static Netlify micro-tools (Mangrove-style niche sites)
  • iOS SwiftUI utility apps
  • Next.js App Router
  • Python FastAPI service

Suggested price band: $49–$149. Recommended as the first offer to launch — lowest support load.

What is the Ship With a Lead-Dev Agent cohort?

Ship With a Lead-Dev Agent is a self-serve, self-paced cohort product. You bring a real repo, install the Lead-Dev system, run Phases 1–3, and greenlight one Phase 4 expansion plan on your own schedule — no live sessions required.

You get case studies, assignments, phase checklists, and a review rubric you can apply yourself. Email is available if you want to ask a question — involvement is optional, not built into the product.

Suggested price band: $297–$997.

What is Agent OS Install (done-with-you)?

Agent OS Install is the done-with-you offer: a lead-developer operating system installed on your repo, a first optimization pass, and a clear expansion backlog handed back to you. Intake is by email only — there is no booking calendar.

What’s included:

  • Email intake + product contract
  • Custom AGENTS.md for your stack and non-goals
  • Custom LEAD_DEV_BUILD_PROMPT.md with your phase order
  • Phase 1 pass executed (or a punch-list if access is limited)
  • Phase 2–3 audit with prioritized backlog
  • Phase 4 idea shortlist (3 niche expansions with rationale)
  • Handoff doc — how to run sessions next week

Timeline: 5–10 business days after scope is agreed by email. Not included: full product rewrite, guaranteed rankings or revenue, ongoing retainer, App Store submission, Netlify billing, or legal review.

Suggested price band: $499–$2,500.

Who is Lead-Dev for — and who is it not for?

A fit if you are a solo builder shipping an app or tool site, already have a messy repo that needs order, or want AI output that matches your architecture.

Not a fit if you want “build me Uber overnight,” have no repo and no intention of touching one, or won’t write a product contract.

Is checkout live yet?

Kit and cohort self-serve checkout buttons on the Lead-Dev page remain placeholders until payment URLs are set in lead-dev/config.js. Until those links are live, those buttons do not send payment data.

Agent OS Install is email-only — use the Lead-Dev page CTA or Contact (needlesearchapp@protonmail.com.

Do tool pages include affiliate links?

Some tool pages include affiliate links (for example to newsletter platforms). Those links may include tracking parameters so a partner can attribute a referral. Affiliate relationships are disclosed with sponsored link attributes where used.

Clicking an affiliate link takes you to a third-party site with its own privacy policy. More detail on the privacy page.
